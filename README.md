## 项目简介

科研助手面向科研爱好者、学生和科研人员，聚焦材料与晶体结构研究中的常用需求：找论文、查物相、获取 CIF、处理结构，以及生成 XRD、SAED 和 HRTEM 计算结果。

你可以直接使用网站，也可以基于本仓库的 Python＋Vue 源码搭建自己的科研工具、改进工作流程或参与开发。

## 能帮你做什么

| 科研需求 | 具体作用 | 可以得到什么 |
| --- | --- | --- |
| 找论文 | 按题名发起文献获取，核对正文身份并查看获取进度 | 已核验全文 PDF 的站内下载 |
| 查物相与衍射卡片 | 按编号或化学式查候选，选中后查看峰位、强度及关联信息 | 可读报告、CSV/JSON 峰表和归档包 |
| 获取晶体结构 | 检索结构记录，下载 CIF，继续用于结构处理与计算 | CIF、结构报告及原子坐标 |
| 处理材料结构 | 结构分析、CIF/POSCAR 转换、XRD衍射峰生成、小超胞生成、两结构比较 | 结构文件、理论峰表、科学图和分析报告 |
| 模拟电镜结果 | 基于 CIF 与指定参数计算 SAED 电子衍射和 HRTEM 图像 | PNG/TIFF 图像、NPY/CSV 数值及计算参数 |
| 查阅科研资料 | 按分类浏览和下载已发布资料 | 有权使用的科研资料附件 |

例如，你可以获取一个结构 CIF，在材料工具中生成理论 XRD 峰，再把该结构用于电子衍射模拟，保留输入、参数和数值，方便后续核对与分析。输入范围和操作见[功能详解](./docs/FEATURES.md)。

## 从哪里开始

- **直接使用工具**：进入上方网站，选择“文献求助”“XRD 晶相”“材料工具”“电镜模拟”或“资料库”。
- **学习或复用源码**：阅读[源码指南](./docs/SOURCE_GUIDE.md)，了解结构处理、科学计算、结果复验和网页交互的实现。
- **搭建自己的服务**：按[部署指南](./deploy/README.md)准备环境，选择启用需要的模块。

## 源码与数据

仓库提供中文网页、Python 后端、科研工具适配、测试及 Linux 容器部署模板。结构处理与科学计算可使用自己有权使用的 CIF；部分材料工具也支持 POSCAR。

**本仓库不提供卡片数据库、派生索引或结构库。** 数据库相关模块只提供适配代码；自行部署需要准备合法数据。文献来源账号、SMTP 和运行配置也由部署者提供，仓库不含原站用户数据或密钥。

科学计算结果属于理论结果，输入、模型及参数限制见详细文档。网站的服务状态、费用和下载期限以网页当次提示为准。
