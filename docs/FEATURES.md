# 功能与科研场景

在线入口见[仓库首页](../README.md)。下面按输入、用途和输出介绍科研工具，帮助你选择合适的功能。

## 文献与物相资料

| 功能 | 提供什么 | 具体作用 | 输出 |
| --- | --- | --- | --- |
| 文献获取 | 论文题名 | 获取并核对正文身份，区分正文与补充材料，查看获取进度 | 已核验全文 PDF，按任务期限下载 |
| XRD 卡片检索 | 编号或化学式，选择衍射候选 | 查找物相资料，核对峰位、强度和卡片信息 | RTF/TXT 报告、CSV/JSON 峰表及原始记录快照包 |
| 晶体结构与 CIF | 结构编号或化学式，选择结构候选 | 获取后续建模所需的晶胞、原子坐标和 CIF | CIF、结构报告、原子坐标 CSV 和 JSON |
| 科研资料库 | 按分类浏览已发布资料 | 集中查阅和下载有权提供的科研资料 | 鉴权附件下载 |

卡片和结构先查候选，再选择所需结果。结构记录不冒充实验峰表，生成报告不冒充软件原生导出。

## 材料工具

可以上传自己有权使用的 CIF，适用操作也支持含明确元素的 POSCAR。当前支持有序满占有结构，不把部分占有或无序结构静默改写。

| 工具 | 具体作用 | 用途与输出 |
| --- | --- | --- |
| 结构分析 | 分析组成、晶胞、位点和受支持的对称性信息 | 核对结构输入，获得中文报告和结构明细 |
| CIF/POSCAR 转换 | 从同一结构导出两种格式，核对晶胞、元素及周期坐标 | 在结构工具与计算软件间传递文件，保留原输入 |
| XRD衍射峰生成 | 按结构、波长和 2θ 范围计算理论粉末衍射峰 | 对照结构与实验趋势；导出 CSV/JSON 峰表及 PNG/SVG 科学图 |
| 小超胞生成 | 按三个整数倍数生成规模限制内的超胞 | 为后续建模准备 CIF/POSCAR、位点 CSV 和结构报告 |
| 两结构比较 | 按容差比较晶格、结构和元素对应关系 | 判断不同来源或格式的结构是否匹配，保留比较参数 |

## 电镜模拟

SAED＋HRTEM 使用 abTEM，根据上传 CIF 或本人已生成并复验的 CIF，在受限模型中计算电子衍射和高分辨透射图像。可设置加速电压、晶带轴、厚度、离焦等参数。

两项结果全部成功并复验后，提供 PNG/TIFF 图像、NPY 数值、CSV/JSON、CIF 和参数记录。结果帮助理解结构与衍射、成像的关系，不替代实验观测，也不意味着任意样品和参数均受支持。

## 怎样串起来用

1. 查阅文献和物相资料，或准备自己的结构文件。
2. 获取或上传 CIF，先核对结构，再按需转换格式、扩胞或比较。
3. 用同一结构生成理论 XRD 峰，或提交电镜模拟。
4. 下载输入、参数、科学图和数值，在自己的研究流程中继续核对。

每个工具也可按页面支持的输入单独使用，操作见[使用指南](./GETTING_STARTED.md)。

功能以当次服务状态与输入校验为准；不能保证任意题名均有全文或任意编号均有记录。科学工具有文件、原子数、模型、资源和时间限制。自行部署不附送数据库或在线站点服务，条件见[源码指南](./SOURCE_GUIDE.md)。
