# 使用指南

从[仓库首页](../README.md)进入网站。上传计算、文献求助和个人任务需注册、验证邮箱并登录；电化学示例可直接查看。

## 分析 GITT、CV 或 DRT

1. 打开“电化学计算”，选择“GITT 扩散系数”“赝电容贡献分析”或“DRT 弛豫时间分析”。首次可下载示例，或登录后载入示例计算。
2. 上传原始数据、填写参数，点击“上传并预览”。GITT 使用四列 Excel；CV 使用至少三个不同正扫速的 CSV/TSV/TXT 或 CHI 原始数据；DRT 使用一份含频率、阻抗实部与虚部的 CSV/TXT。
3. 核对数据列、单位、循环或虚部符号，勾选确认后点击“开始计算”。查看曲线与诊断提示，下载结果包或导出 PNG/SVG。

GITT 四列依次为记录、容量、电压和状态，首表保留两行表头。CV 每个扫速一个文件，需选择完整且可比较的循环。DRT 高斯峰分解需先完成常规 DRT，再选择本人未到期的基础结果。

## 查 XRD 资料或获取 CIF

1. 打开“XRD 晶相”，按卡片编号或化学式输入查询内容；网站会查询全部已接入库。
2. 浏览候选与逐库查询状态，核对编号、化学式及条目类型，选择所需结果。
3. 在当前页面生成并下载报告；晶体结构条目可下载 CIF。

化学式需写明元素计量比例。衍射卡片、索引报告和晶体结构分别标示，来源未完成查询时不要据此判断全部查无。

## 求助论文全文

1. 打开“文献求助”，粘贴完整论文题名并提交。
2. 在本人任务中查看进度，按提示确认候选信息。
3. 成功后下载 PDF；全文获取后保留 3 天，请及时保存。

## 模拟 TEM 或 XRD 衍射

1. 打开“衍射模拟”，选择“TEM衍射斑点”或“XRD衍射峰生成”。
2. TEM 上传 CIF；XRD 上传 CIF/POSCAR。也可选用本人已生成的结构，核对电压、晶带轴、波长等当前模式的参数后提交。
3. 完成后查看并下载结果。TEM 同时提供 SAED 与 HRTEM，SAED 图支持缩放、拖动和点选斑点查看晶面。

当前支持有序、满占有结构。模拟结果与实验现象比较时，应同时核对结构、取向和模型条件。

## 处理 VASPKIT 文件

1. 打开“VASPKIT工具”，按名称、任务编号或分类选择已开放的功能。
2. 按“需要文件”提示选择文件或计算目录，填写参数；无需文件的功能可直接填写参数。
3. 点击“提交处理”，完成后下载结果包。

## 查资料与交流问题

1. 在“资料库”搜索文件名或描述，查看资料说明。
2. 点击“下载”获取附件，或使用“下载文件夹”“下载当前文件夹”保存整个目录。
3. 在“交流论坛”搜索相关问题；需要进一步讨论时，点击“提出问题”或进入问题页回答、关注。

## 保存结果与反馈

电化学、文献、模拟和 VASPKIT 的个人结果保留 3 天。下载时留存原始数据与实际参数，结合页面的适用条件解释结果。

费用和任务状态以网页提示为准。遇到问题可提交 [Issue](https://github.com/Sledge123/research-assistant/issues)，附功能名称、实际提示和复现步骤，避免上传凭据或私人数据。网站功能与仓库源码范围的区别见[源码指南](./SOURCE_GUIDE.md)。
