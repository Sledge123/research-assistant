# 使用指南

在线入口见[仓库首页的“访问科研助手”](../README.md)。进入网站，按页面提示完成正常注册、邮箱验证和登录，选择需要的科研功能。状态、费用、输入限制及下载期限以当次网页提示为准。

## 我想找论文

1. 打开“文献求助”，输入论文题名并提交。
2. 查看获取进度，结果会核对正文身份。
3. 成功后在本人任务中下载 PDF，留意有效期。

题名不明确、来源不可用或无合格正文时，可能无法获取。不要把补充材料当作正文，遵守文献来源与使用权限。

## 我想查物相或下载 CIF

1. 打开“XRD 晶相”，选择衍射卡片或晶体结构内容。
2. 输入编号或化学式，查看并分页浏览候选。
3. 选中需要的候选，再生成和下载报告；结构结果可下载 CIF。

衍射卡片用于查看峰位、强度等资料，CIF 用于后续结构处理与计算。化学式按明确元素计量比例检索，不能用未知变量代替具体组成。

## 我已经有结构文件

打开“材料工具”，选择结构分析、CIF/POSCAR 转换、XRD衍射峰生成、小超胞生成或两结构比较；上传自己有权使用的结构、设置参数，再查看进度和下载结果。

想观察电子衍射与成像关系时，打开“电镜模拟”，上传 CIF 或复用本人已生成并复验的 CIF，设置参数，待 SAED 和 HRTEM 都完成后下载图像与数值。

首次可从结构分析开始，先核对晶胞、元素及原子位置。当前支持有序满占有结构，遇到拒绝提示应检查输入和模型范围。

## 我想找科研资料

打开“资料库”，按分类浏览已发布资料，查看说明后下载；内容取决于站点实际发布情况。

## 如何看待结果与反馈问题

保留输入和实际参数，结合模型假设与实验背景解释理论结果。失败原因、下载期限及下一步以本人任务页为准。

遇到问题可提交 [Issue](https://github.com/Sledge123/research-assistant/issues)，说明功能、预期行为、实际提示和复现步骤。不要附凭据、私人全文、数据库或未授权记录。自行部署见[部署指南](../deploy/README.md)。
