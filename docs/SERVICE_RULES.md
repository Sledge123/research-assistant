# 任务费用与有效期

本文件供理解和部署当前源码时参考。在线费用、状态与期限以网页当次提示为准。

| 功能 | 成功费用 | 条件 |
| --- | --- | --- |
| 科研资料库 | 免费 | 已验证账号下载已发布资料 |
| XRD/结构检索与候选分页 | 免费 | 已接入可用数据源 |
| XRD/结构归档 | 每项 1 积分 | 服务器复验成功后结算 |
| 文献获取 | 每篇 1 积分 | 已取得并核验正文 |
| SAED＋HRTEM | 两项全部成功合计 1 积分 | 独立 abTEM 执行器 |
| XRD衍射峰生成 | 每次 2 积分 | 独立 pymatgen 执行器 |
| 其他材料工具 | 每次 1 积分 | 结构分析、转换、超胞或比较 |

提交时服务器原子冻结积分，成功复验后结算，失败、取消或超时按原冻结额返还。历史免费任务不补扣，重复请求及回执保持幂等。

文献及科学结果默认从成功起保留 3 天，有效期内鉴权重复下载免费，实际期限以任务为准。检索、选卡和重复下载不另收费。
